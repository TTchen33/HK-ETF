# ETF 溢价／折价监测方法

## 目标

将发行商公布的每单位净值与市场价格放到同一日期、同一币种后比较，展示历史日终的溢价或折价。该指标用于数据工程与分析演示，不是实时交易信号。

## 计算流程

1. 读取产品目录中的 `navPerShare`、`navCurrency` 与 `asOfDate`。
2. 只接受与 `asOfDate` 完全相同的 ETF 日线收盘价。
3. 港元净值直接使用；美元净值使用 USD/HKD，人民币净值使用 CNY/HKD 公开汇率换算。
4. 汇率优先使用同日数据；遇到外汇市场日期缺口时，最多向前匹配 3 个自然日并标为近似换算。
5. 计算：`(同日收盘价 / 港元换算净值 - 1) × 100%`。

正值显示为溢价，负值显示为折价。如果缺少净值、同日收盘价、支持的币种或有效汇率，记录会标记为不可计算。

## 数据来源与限制

- ETF 日线与 USD/HKD、CNY/HKD 历史汇率由 Yahoo Finance 经 yfinance 自动采集。
- 人民币净值可能以离岸人民币口径公布，CNY/HKD 只作为公开汇率近似，因此界面会标记为“近似换算”。
- 发行商净值与交易所收盘价的发布截止时间可能不同，即使日期相同仍可能存在时点差。
- 本模块不是交易所实时 iNAV，也不代表可成交价格或 ETF 申购赎回资金流。

## 可展示的工程能力

- 跨来源数据对齐：产品净值、证券行情与外汇时间序列。
- 数据质量防线：严格日期匹配、币种校验、有限回溯与不可计算状态。
- 可解释分析：每只 ETF 都能展开查看完整换算公式和数据状态。
- 自动化：汇率随现有 GitHub Actions 行情任务一并刷新，无需人工操作。
